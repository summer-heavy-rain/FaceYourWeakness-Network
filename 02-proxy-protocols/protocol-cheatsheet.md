## 快速决策树

```
你的需求是什么？
│
├── 速度优先（下载大文件、看视频）
│   └── 试 Hysteria2
│       ├── 快 → 用它
│       └── 不通/反而更慢 → 你的网络限制 UDP → 换 VLESS+WS+TLS 或 Trojan
│
├── 稳定优先（工作、写代码、开会）
│   └── Trojan 或 VLESS+WS+TLS
│       ├── 正常 → 用它
│       └── 不通 → 节点 IP 可能被封 → 试 VMess+WS+TLS 过 CDN
│
├── 公司/校园网络（限制严格）
│   └── Trojan on port 443（看起来跟正常 HTTPS 一模一样）
│       ├── 正常 → 用它
│       └── 还是不通 → 网络可能有 DPI 深度包检测 → 联系机场客服问有没有专用节点
│
└── 所有协议都不稳定
    ├── 换不同地区的节点（HK/JP/SG/US）
    ├── 换 ISP 出口（WiFi vs 移动数据）
    └── 可能是 GFW 在搞事 → 等一阵通常会恢复
```

## Port 443 的特殊地位

443 是 HTTPS 的标准端口。**整个互联网的加密 Web 流量都走这个端口。**

为什么这对你很重要：

1. **GFW 不会封 443 端口**——封了等于把整个互联网的 HTTPS 都干掉，不可能
2. **代理服务器跑在 443 端口 + TLS 加密** = 跟正常网站流量完全一致
3. 如果你的某个节点用了非标准端口（比如 8443、2083）并且被封了，看看机场有没有 443 端口的节点

### 常见端口和含义

| 端口 | 用途 | GFW 态度 |
|------|------|----------|
| 443 | HTTPS（标准） | 不敢封 |
| 80 | HTTP（明文） | 不敢封，但明文无法用于加密代理 |
| 8443, 2053, 2083, 2087, 2096 | Cloudflare 支持的 HTTPS 备用端口 | 有时会被针对性封锁 |
| 其他高位端口 | 自定义 | 容易被封 |

## CDN 中转

### 什么是 CDN 中转

```
正常代理：
  你 ──→ 代理服务器 ──→ 目标网站
  问题：GFW 可以直接封代理服务器的 IP

CDN 中转：
  你 ──→ Cloudflare CDN ──→ 代理服务器 ──→ 目标网站
  优势：GFW 封不了 Cloudflare——太多正常网站在用
```

### 支持 CDN 中转的协议

只有基于 WebSocket 的协议能走 CDN：
- **VMess + WS + TLS** ✓
- **VLESS + WS + TLS** ✓
- Trojan ✗（标准 Trojan 不支持，Trojan-Go 的 WS 模式支持）
- Hysteria2 ✗（UDP 协议，CDN 不支持 UDP 转发）
- SS ✗（没有 WS 传输层）

### 什么时候需要 CDN 中转

- 代理服务器 IP 被 GFW 直接封锁（直连不通）
- 你的 ISP 对代理服务器 IP 限速

### 代价

- **速度更慢**：多了一跳（你 → CDN → 代理服务器），延迟增加 20-50ms
- **不如直连快**：CDN 本身有带宽限制
- 是一个**保底方案**，不是首选

## 本地代理协议 vs 翻墙协议（别搞混）

```
App ──[HTTP/SOCKS5]──→ Clash ──[SS/VMess/Trojan/...]──→ 远程服务器 ──→ 目标
│                      │                                │
│ 本地协议（App↔Clash）  │ 翻墙协议（Clash↔远程服务器）     │
│ 你配的 http.proxy     │ 机场订阅里定义的               │
```

- `http.proxy = http://127.0.0.1:7897` → 这是**本地 HTTP 代理**协议
- 节点列表里的 `trojan`、`vmess` → 这是**翻墙协议**
- 两层各管各的，不要混为一谈

## 你的 NxOnEarth 订阅：实操建议

1. **不要手动挑节点/协议**：配一个 `url-test` proxy group，让 Clash 自动选延迟最低的
2. **如果自动选的不好使**：手动试试不同协议——先试 Trojan，再试 Hysteria2，最后试 VMess+WS+TLS
3. **如果所有节点都不通**：
   - 检查订阅是否过期
   - 刷新订阅（机场可能更新了节点）
   - 检查 Clash Verge 日志看报错信息
4. **晚高峰慢**：试 Hysteria2（如果你的网络支持 UDP）
5. **公司网不通**：Trojan on 443，或者开手机热点绕过公司网络

| 情况 | 用什么 |
